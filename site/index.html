What this shows

The forest is predicting the price level. A forecast that tracks the last close can look close on a chart and still be worse than guessing that tomorrow equals today. The gap is the number in the ratio column, not a story about the line hugging the price.

The equity curve answers a different question: what a long/flat rule would have done with that same next-day level forecast. Long when the forecast is above today's close, otherwise flat. A position change is filled at the next bar's open, commission is 0.1%, and the book starts at $10,000. Buy and hold buys at that same first tradable open and pays the same entry commission. It is a historical simulation on the last walk-forward fold, with no slippage model. It is not a live track record, and it does not change the error comparison above.

The LSTM is not on this page. Training it is too heavy for this static demo, and it would still be aiming at the price level.

Planned next step: predict the next-day return instead of the price, and score that forecast against persistence, which for a return is zero.
